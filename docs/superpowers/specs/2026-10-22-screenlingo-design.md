# ScreenLingo: дизайн

Дата: 2026-10-22. Статус: одобрено в чате.

## Цель
Программа для Windows, которая переводит любой текст на экране поверх оригинала: в играх, программах, видео, картинках. Должна быть полезна каждый день и хорошо смотреться в портфолио (GitHub, Авито, Kwork, ТГ-канал).

Что сказал пользователь: оба режима (снимок и живая зона); перевод с любого языка на любой; только онлайн-перевод.
Допущения: Windows 10/11; распространяем как один .exe через GitHub Releases.

## Стек
- Python 3.14, PySide6 (окна, трей, оверлей), mss (снимки экрана), RapidOCR на onnxruntime (распознавание текста локально), requests (перевод).
- Сборка: PyInstaller, один файл или одна папка.
- Тесты: pytest.

## Режимы
1. **Снимок** (по умолчанию Alt+Q). Экран затемняется, пользователь выделяет прямоугольник. Распознаём строки с координатами, переводим и рисуем перевод поверх каждой строки (фон под цвет оригинала, текст подогнан по размеру). Рядом панель: исходный текст, перевод, «Копировать», выбор языка. Esc или клик вне окна закрывает.
2. **Живая зона** (по умолчанию Alt+W). Выделяем область, вокруг неё тонкая рамка. Раз в ~0,5 с делаем снимок и сравниваем с прошлым (уменьшенная серая картинка и средняя разница пикселей). Если картинка изменилась и потом ~0,3 с не менялась, распознаём и переводим. Окно перевода прозрачно для кликов и находится над зоной или под ней (настраивается). Повторное нажатие Alt+W или пункт в трее выключает зону.

## Языки
- Перевод: Google Translate (бесплатный веб-адрес translate.googleapis.com, client=gtx), 130+ языков, исходный язык «auto». Запасной: MyMemory API.
- Распознавание: модели RapidOCR по письменностям: латиница, кириллица, китайский (с английским), японский, корейский, арабский, деванагари, тайский, греческий. В настройках выбирается письменность исходного текста. «Авто» по умолчанию берёт модель «китайский+английский+латиница». Нужные модели скачиваются при первом использовании; если в библиотеке их нет, пункт честно помечается как недоступный.

## Компоненты (каждый файл отвечает за одно)
- `capture.py`: снимок области экрана в numpy-массив (mss), с учётом масштаба DPI.
- `ocr.py`: обёртка над RapidOCR: картинка → список строк (текст, прямоугольник, уверенность); склейка строк в абзацы.
- `translate.py`: интерфейс `Translator.translate(texts, src, dst)`; GoogleTranslator, MyMemoryTranslator, FallbackTranslator; кэш (LRU) по ключу (текст, src, dst).
- `change.py`: детектор изменений для живой зоны (чистая логика, без Qt).
- `hotkeys.py`: глобальные горячие клавиши через Win32 RegisterHotKey (ctypes), сигналы в Qt.
- `settings.py`: настройки в JSON в `%APPDATA%\ScreenLingo\settings.json`.
- `ui/selector.py`: полноэкранное выделение области.
- `ui/overlay.py`: рисует перевод поверх строк.
- `ui/panel.py`: панель с текстом и кнопками.
- `ui/live.py`: рамка и окно живой зоны, таймер, поток работы.
- `ui/settings_dialog.py`, `ui/tray.py`.
- `app.py`: сборка всего вместе, точка входа.
Распознавание и перевод выполняются в фоновом потоке (QThreadPool), интерфейс не зависает.

## Ошибки
- Нет сети или переводчик не ответил: пробуем запасной; если и он не ответил, показываем оригинал с пометкой «нет сети».
- Текст не найден: короткая подсказка «Текст не найден».
- Модель письменности не скачалась: сообщение и откат на модель по умолчанию.
- Горячая клавиша занята другой программой: уведомление в трее и предложение сменить её в настройках.

## Приватность
Скриншоты не покидают компьютер. В интернет уходит только распознанный текст.

## Ограничение
Игры в эксклюзивном полноэкранном режиме не дают рисовать поверх себя; работаем в оконном режиме и в оконном без рамки.

## Тестирование
- pytest: change.py, кэш и fallback в translate.py (HTTP подменён), склейка строк в ocr.py, settings.py.
- Интеграционный тест OCR на сгенерированных картинках с английским и японским текстом.
- Ручная проверка: снимок и живая зона на реальном экране; запуск собранного .exe.
